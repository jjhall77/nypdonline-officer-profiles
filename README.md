# nypdonline-officer-profiles

> Independent daily archive of NYPD officer profile data, maintained by John
> Hall for research use. Continuation of the public archive originally run by
> Ryan Watkins (scraper code MIT, see LICENSE) after the original repos were
> deleted in July 2026. Data is scraped from nypdonline.org, a public NYPD
> transparency site.

Tracking NYPD Officer Profile data from nypdonline.org

> yarn start

Scrapes all profile data and trial decisions.

> yarn tocsv

Generate CSV versions of profile data.

Commit history contains only JSON format without 'training' data.
Automated workflow action archives only the most recent version of all data.
